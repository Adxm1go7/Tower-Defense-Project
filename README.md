# Slyme Defender

## Project Overview
This project is a unity based tower defence game, developed as a group of 4.
Our game has contains multiple unique animated towers and their upgrades,
waves of enemies and a resource management system in coins, playable across 4
unique maps.

## Game Features
- 8 Unique Animated Towers
- Tower Upgrades
- Player Controlled Hero
- 4 Unique maps
- Hero Upgrades
- Coin and life system
- 8 unique animated enemies 
- Progressively more difficult enemy waves
- WebGL build

## Controls:
- Left click : Select towers and hero
- Esc : Open up menu to select homepage, sound, and game speed settings
- Mouse : Used to place towers and navigate the menus
- W A S D : Used to control the hero

## Instructions On How To Play:

1. Run WebGL.

2. Opens to home screen, select Play

3. Pick one of the 4 maps

4. Control the hero with W A S D

6. Place Towers and control the hero to defend the horde of incoming Slymes

7. Click on the Towers and Hero to upgrade them to make them stronger against the progessively harder hordes of Slymes

8. At any point press Esc to change the sound, and game speed or go back and change maps or difficulties.

9. Keep fighting the slymes until the rounds end or you lose!
